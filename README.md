# Яся — игры для развития

PWA-хаб развивающих игр для ребёнка 3–4 лет. Vanilla HTML/JS, без сборки и зависимостей.
Работает офлайн на iPad после установки через Safari → «Поделиться» → «На экран “Домой”».

## Игры

| Плитка | Файлы | Что делает |
|---|---|---|
| 🎨 Цвета | `games/colors/` | «Покажи красный шарик» — 5 раундов, задание озвучивается |
| 🃏 Пары | `games/memory/` | мемори на 3 пары зверят |
| 🔢 Счёт | `games/count/` | посчитать 1–5 предметов, выбрать цифру |
| 🐮 Звуки | `games/sounds/` | 16 животных с настоящими записями голосов |
| 🌓 Тени | `games/shadows/` | найти картинку по силуэту |
| 🖍️ Раскраска | `games/paint/` | 16 картинок-контуров из эмодзи, рисование пальцем по холсту, 17 цветов + ластик |
| 🧩 Пазл | `games/puzzle/` | 2×2 → 3×3, drag-and-drop (Pointer Events) |
| 🫧 Пузыри | `games/bubbles/` | лопать летящие пузырьки, 10 штук |
| 🔔 Повтори | `games/simon/` | повторить мелодию из 4 нот, 5 уровней |
| 🧺 Корзины | `games/baskets/` | drag: разложить фрукты и овощи по корзинкам |
| 🐘 Большой | `games/size/` | показать большого или маленького |
| 🎧 Кто сказал? | `games/whosaid/` | звучит голос зверя — угадать, кто из трёх |
| 🔍 Лишний | `games/odd/` | найти предмет не из той категории |
| 🔤 Ряд | `games/pattern/` | продолжить логическую цепочку |
| 🌀 Лабиринт | `games/maze/` | провести мышку к сыру пальцем |
| 🎹 Пианино | `games/piano/` | 8 клавиш-нот, свободная игра и мелодия |

За каждую пройденную игру — ⭐ (всего звёзд видно в панели для родителей).

## Родителям

Долгое нажатие (~1 сек) на заголовок «🌟 Игры Яси 🌟» на главном экране:
вкл/выкл звука и озвучки, выбор системного голоса, число звёзд, сброс прогресса (двумя тапами).

## Озвучка

Все реплики озвучены клоном голоса (F5-TTS, проект `D:\Coding\voicegen`).
Файлы лежат в `assets/voice/<percent-encoding фразы>.mp3`; `speak()` играет файл,
при его отсутствии — системный синтез. Полный список фраз — в `voicegen/batch_yasya.py`
(держать в точном соответствии с кодом игр!). Перегенерация:

```
cd D:\Coding\voicegen
.venv\Scripts\python.exe batch_yasya.py
```

Затем поднять версию `CACHE` в `sw.js`. Манифест файлов для офлайна
(`assets/voice/manifest.js`) обновляется скриптом автоматически.

## Структура

- `index.html` — хаб (сетка плиток-игр)
- `games/<имя>/index.html` — каждая игра в своей папке, самодостаточная
- `js/core.js` — общее ядро: звуки (WebAudio + разблокировка для iOS), речь
  (SpeechSynthesis, ru-RU), настройки, прогресс (localStorage), экран победы
- `sw.js` — Service Worker, офлайн-кэш. **При изменении файлов подними версию `CACHE`!**
- `tools/make-icons.mjs` — генератор иконок (`node tools/make-icons.mjs`)
- `tools/server.mjs` — дев-сервер (`node tools/server.mjs [порт]`)

## Локальный запуск

```
node tools/server.mjs
```

Открыть http://localhost:8000. Service Worker на localhost не включается
(правки видны сразу); офлайн проверяется на задеплоенном URL.

Тестировать лучше в Safari — движок iPad тоже Safari (WebKit).

## Деплой на GitHub Pages

1. Создай репозиторий на GitHub (например, `yasya`) и запушь:
   ```
   git remote add origin https://github.com/<логин>/yasya.git
   git push -u origin master
   ```
2. Settings → Pages → Source: ветка `master`, папка `/ (root)` → Save
3. Через минуту приложение живёт на `https://<логин>.github.io/yasya/`

Пути в проекте относительные, поэтому подкаталог Pages работает из коробки.

## Установка на iPad

1. Открой URL приложения в Safari (не в Chrome)
2. Поделиться → «На экран “Домой”» → Добавить
3. Запускай с домашнего экрана — на весь экран, без панелей браузера, работает офлайн

## Добавление новой игры

1. Скопируй структуру `games/colors/index.html`
2. Добавь плитку в `index.html` и страницу в `ASSETS` в `sw.js` (+ бамп версии кэша)
3. Общие стили игровых элементов — в `css/style.css`
