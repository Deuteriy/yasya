# Яся — игры для развития

PWA-хаб развивающих игр для ребёнка 3–4 лет. Vanilla HTML/JS, без сборки.
Работает офлайн на iPad после установки через «Поделиться → На экран “Домой”».

## Структура

- `index.html` — хаб (сетка плиток-игр)
- `games/<имя>/index.html` — каждая игра в своей папке
- `js/core.js` — общее ядро: звук (WebAudio, разблокировка для iOS), прогресс (localStorage)
- `sw.js` — Service Worker, офлайн-кэш. **При изменении файлов подними версию `CACHE`!**
- `tools/make-icons.mjs` — генератор иконок (`node tools/make-icons.mjs`)

## Локальный запуск

Нужен HTTPS для проверки PWA-фич, но для разработки хватит любого статического сервера:

```
npx serve .
# или
python -m http.server 8000
```

Открыть http://localhost:8000 — лучше в Safari (движок iPad).

## Деплой

GitHub Pages: Settings → Pages → ветка main. HTTPS будет автоматически.

## Добавление новой игры

1. Скопируй структуру `games/colors/`
2. Добавь плитку в `index.html` и ссылку в `ASSETS` в `sw.js` (+ бамп версии кэша)
